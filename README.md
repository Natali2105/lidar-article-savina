# Сравнительный анализ качества прямых и зеркально-отражённых LiDAR-измерений при варьировании угла падения

## Описание проекта

Данный репозиторий содержит исходный LaTeX-код научной статьи, посвящённой исследованию радиометрических и геометрических характеристик облаков точек, полученных с помощью LiDAR при прямой и зеркально-отражённом сканировании.

* **Автор:** Н. Д. Савина

* **Научный руководитель:** М. Р. Вишневский

* **Аффилиация:** Кафедра инженерной кибернетики, НИТУ «МИСиС»

* **Формат статьи:** Шаблон НИТУ «МИСиС» (`misisarticle.cls`)

## Актуальность и исследовательский пробел

В мобильной робототехнике и беспилотных транспортных средствах (БПЛА, автономные автомобили) зеркальная аугментация используется для расширения поля зрения (FOV) и устранения слепых зон без установки дополнительных сенсоров.

Существующая литература разделена на два изолированных направления:

1. **Влияние угла падения на радиометрию:** исследования изучают только прямое освещение (Soudarissanane 2009, Glennie 2020, Zhang 2023).

2. **Зеркальная аугментация LiDAR:** исследования сосредоточены исключительно на геометрии и калибровке (Li 2021, Kim 2019, Soquita 2025).

**Пробел в науке:** отсутствие систематической характеризации радиометрии (интенсивности, уровня шума, вероятности обнаружения) зеркально-отражённых измерений как функции угла падения с учётом модели «двойного пути» луча.

## Научная гипотеза

Предполагается, что при зеркально-отражённых LiDAR-измерениях зависимость интенсивности сигнала от угла падения не подчиняется стандартному закону косинуса Ламберта из-за эффекта **двойного пути** (LiDAR $\rightarrow$ зеркало $\rightarrow$ цель $\rightarrow$ зеркало $\rightarrow$ LiDAR) и затухания энергии на зеркале (потери $\sim R^{-4}$ против $R^{-2}$ при прямом луче).

С увеличением угла падения на зеркало ($\alpha > 30^\circ\text{--}45^\circ$) вероятность обнаружения объектов с низкой отражательной способностью (чёрные поверхности) резко снижается по сравнению с прямым сканированием под тем же углом.

## 🛠 Экспериментальная установка и данные

* **Оборудование:** LiDAR Velodyne VLP-16, плоское оптическое зеркало, эталонные мишени (белая, серая, чёрная).

* **ПО:** ROS Noetic, нода `mirror_live_node` (сохранение поля `intensity` FLOAT32, offset=12; экспорт в `.pcd`).

* **Сетка параметров:** Углы падения $\{0^\circ, 15^\circ, 30^\circ, 45^\circ, 60^\circ\}$ $\times$ 3 типа поверхностей.

* **Метрики:** Средняя интенсивность, отношение сигнал/шум (SNR), число точек на импульс, шум дальности, вероятность обнаружения.

1. Откройте `article.tex`.

3. Заполните коды, название, авторов, аннотацию и ключевые слова.

В Overleaf загружайте не весь репозиторий, а архив без примера:


3. Главный файл — `article.tex`. Заполните блоки и нажмите Recompile.

### Локально

```bash
# macOS: MacTeX, либо brew install tectonic
make article
# PDF: build/article.pdf

# либо прямо:
tectonic article.tex
xelatex article.tex && xelatex article.tex
```

Файл `misisarticle.cls` должен лежать рядом с вашим `.tex`.

## Что заполнить в `article.tex`

1. `\grnti{}`, `\asjc{}`, `\oecd{}` — коды, либо `{}`, если код не нужен.
2. `\title{}` — название.
3. `\misisauthor{ФИО}{кафедра}{город, страна}{email}` — на каждого автора. Первый попадает в левую колонку, остальные — в правую.
4. `\abstract{}` или `\setabstract{}`, `\keywords{}` или `\setkeywords{}`. Пары команд эквивалентны.
5. Разделы `\section{}`, `\subsection{}`, рисунки, таблицы и список `\begin{thebibliography}`.

Список литературы набирается вручную в `thebibliography`. Класс оформляет этот список сам.

### Минимальный пример

```latex
\documentclass{misisarticle}

\grnti{47.01.07, 47.01.09}
\asjc{1707, 2207}
\oecd{1020, 1070}

\title{Название статьи}

\misisauthor{И.~О.~Иванов}{кафедра ... НИТУ «МИСиС»}{Москва, Россия}{student@edu.misis.ru}
\misisauthor{П.~П.~Петров}{кафедра ... НИТУ «МИСиС»}{Москва, Россия}{student2@edu.misis.ru}

\setabstract{Текст аннотации...}
\setkeywords{ключевое слово 1, ключевое слово 2}

\begin{document}
\maketitle

\section{Введение}
Текст раздела...
\end{document}
```

## Оформление

| Элемент | Параметры |
|---------|-----------|
| Формат | A4, **две колонки** (IEEE-style) |
| Поля | верх 1,9 см; низ 2,54 см; лево/право 1,57 см; зазор колонок 0,635 см |
| Шрифт | Times New Roman, **10 pt** (в двухколоночном режиме). Если шрифта нет, класс берёт TeX Gyre Termes |
| Переносы слов | **отключены** по всему документу |
| Абзацный отступ | 0,51 см |
| Классификация | `ГРНТИ …`, `ASJC …`, `OECD …` — подпись и коды **в одной строке** |
| Название | 24 pt, по центру, на всю ширину; после него — строка отступа |
| Авторы | 11 pt; невидимая таблица: **1-й слева, 2-й справа**, между колонками пустой зазор; внутри каждой ячейки текст **по центру** |
| Аннотация | **Аннотация —** текст (метка и текст **жирным**, в колонках) |
| Ключевые слова | **Ключевые слова —** текст (жирным) |
| Раздел | **I. ВВЕДЕНИЕ** — римские цифры, small caps, по центру |
| Подраздел | *A. LISA* — буквы A, B, C…, курсив |
| Подписи рисунков | «Рис. N.», мелкий шрифт |
| Подписи таблиц | «Таблица I.» (римские цифры) |
| Литература | заголовок **ЛИТЕРАТУРА** по центру; `[N]` и текст на одной строке, мелкий шрифт |

## Пример

Каталог `example/` — полная статья, по которой сверяется класс. Это не заготовка для новой работы.

```bash
make example
# готовый PDF для просмотра: example/build/example.pdf
```

Рядом с `example.tex` лежит ссылка `misisarticle.cls` на класс в корне, поэтому команда `\documentclass` такая же, как в шаблоне. PDF шаблона и примера можно скачать из артефактов [GitHub Actions](https://github.com/sadekovlar/misis-article-latex/actions): `article.pdf` и `example.pdf`.
