# Сравнительный анализ качества прямых и зеркально-отражённых LiDAR-измерений при варьировании угла падения

## Описание проекта

Данный репозиторий содержит исходный LaTeX-код научной статьи, посвящённой систематической характеризации радиометрических и геометрических параметров облаков точек, полученных с помощью LiDAR при прямом и зеркально-отражённом сканировании.

## Актуальность и исследовательский пробел

В робототехнике и беспилотных транспортных средствах (БПЛА, автономные автомобили) зеркальная аугментация позволяет расширить поле зрения (FOV) и устранить слепые зоны (например, под колёсами или за бампером) без установки дополнительных сенсоров.

Существующая литература разделена на два изолированных направления:

1. **Влияние угла падения на радиометрию:** изучалось только для прямого освещения (*Soudarissanane 2009*, *Glennie 2020*, *Zhang 2023*).
2. **Зеркальная аугментация LiDAR:** исследовалась только с точки зрения геометрии, калибровки и FOV (*Li 2021*, *Kim 2019*, *Soquita 2025*).

**Пробел в литературе:** отсутствие исследования радиометрии (интенсивности, уровня шума, вероятности обнаружения) зеркально-отражённых измерений как функции угла падения с учётом модели **«двойного пути»** луча ($\text{LiDAR} \rightarrow \text{зеркало} \rightarrow \text{цель} \rightarrow \text{зеркало} \rightarrow \text{LiDAR}$).

## Научная гипотеза

Предполагается, что при зеркально-отражённых LiDAR-измерениях зависимость интенсивности сигнала от угла падения не подчиняется стандартному закону косинуса Ламберта из-за эффекта **двойного пути** луча и потерь энергии при отражениях (затухание $\sim R^{-4}$ против $R^{-2}$ при прямом сканировании).

С увеличением угла падения на зеркало ($\alpha > 30^\circ\text{--}45^\circ$) вероятность обнаружения объектов с низкой отражательной способностью (чёрные поверхности) резко снизится по сравнению с прямым сканированием тех же объектов под тем же углом.

## Экспериментальная установка и данные

* **Оборудование:** LiDAR Velodyne VLP-16, плоское оптическое зеркало, эталонные мишени (белая, серая, чёрная).
* **Программное обеспечение:** ROS Noetic, нода `mirror_live_node` (сохранение поля `intensity` FLOAT32, offset=12; экспорт в `.pcd`).
* **Сетка параметров:** Углы падения $\{0^\circ, 15^\circ, 30^\circ, 45^\circ, 60^\circ\}$ $\times$ 3 типа поверхностей.
* **Метрики:** Средняя интенсивность, отношение сигнал/шум (SNR), число точек на импульс, шум дальности, вероятность обнаружения.

## Инструкция по сборке

### Требования

* Компилятор: **XeLaTeX** (или `tectonic`).
* Шрифты: Times New Roman (при отсутствии используется TeX Gyre Termes).

### Варианты сборки

#### 1. Локально через Makefile

```bash
make article
# Итоговый PDF сохранится в build/article.pdf
```

#### 2. Локально через консоль

```bash
# Через XeLaTeX:
xelatex article.tex && xelatex article.tex

# Или через Tectonic:
tectonic article.tex
```

#### 3. В Overleaf

1. Сформируйте zip-архив без каталога `example/`:
   ```bash
   make dist
   ```
2. Загрузите полученный `dist/misis-article.zip` в Overleaf (*New Project* $\rightarrow$ *Upload Project*).
3. В настройках Overleaf переключите компилятор: **Menu** $\rightarrow$ **Compiler** $\rightarrow$ **XeLaTeX**.
4. Нажмите **Recompile**.
